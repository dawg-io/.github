# dawg-io

Open-source software for platform engineering, GitOps, Kubernetes, and Home Assistant.

dawg-io develops and maintains practical tools for operating self-hosted infrastructure, managing software delivery, and extending Home Assistant.

## Project Areas

### Platform Engineering

- **ActionsManager** — A self-hosted, multi-repository control plane for managing GitHub Actions workflows, reusable workflows, configuration drift, and pull-request-based delivery.
- **FluxCD Ezy** — A reference implementation for building and managing GitOps-based Kubernetes environments with FluxCD.

### Home Assistant

- Approved HACS integrations for NOAA weather and environmental data and FluxCD monitoring
- Custom Home Assistant integrations for additional services and devices
- Lovelace cards for visualizing infrastructure and FluxCD resources
- Reusable Home Assistant automation blueprints
- Kubernetes deployment configurations for running Home Assistant and its supporting services

### Kubernetes and GitOps

Reusable Kustomize and FluxCD deployment projects for self-hosted applications, including:

- Home Assistant
- Zigbee2MQTT
- Eclipse Mosquitto
- Z-Wave JS UI
- Mealie
- Network UPS Tools
- Network and speed-test utilities

## Project Philosophy

Projects are designed around practical operation, clear documentation, reproducible deployment, and maintainable automation.

The organization includes complete applications, Home Assistant integrations, frontend cards, automation blueprints, GitOps references, and reusable Kubernetes deployment configurations.

Refer to each repository for installation instructions, release status, and support details.
